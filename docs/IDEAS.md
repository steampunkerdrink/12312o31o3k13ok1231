# Идеи и бэклог

Черновики и отложенные идеи для VK CLI-бота. Не спецификация — просто «на подумать».
При реализации переносим в `CHANGELOG.md`, а отсюда убираем.

## SSH-режим (особый режим работы внутри ssh)

**Проблема.** ART-шапка строится из **локальных** значений (`user@host:last_valid_path`),
поэтому внутри `ssh` она врёт: показывает хост/путь бота (`root@v2858132…:/root#`), тогда как
команда выполняется на удалённой машине (`root@debian:~/test#`). Плюс удалённый промпт
«протекает» в тело картинки последней строкой.

**Идея.** Ввести явное состояние «мы в ssh».

Вход в режим:
- авто: пользователь запускает `ssh …` / `mosh …` (это и так идёт в живую сессию) → `ssh_mode = True`;
- ручной флаг (fallback для нестандартных промптов): команда вида `ssh <метка>`.

Выход: `exit` / `logout`; `reset` / hard-reset; новый `ssh` к другой машине (переустановка метки);
страховка — ручное `ssh off`.

Варианты шапки в ssh-режиме:
- **S1 (предпочтительно):** брать шапку из **удалённого промпта** — парсить последнюю
  prompt-строку (`user@host:path#`) в захваченном выводе, приписать команду и **вырезать** её из
  тела. Локально (у нас `PS1=''`) промпта нет → остаётся синтетическая шапка.
- **S2:** не рисовать свою шапку вовсе — оставить удалённый промпт в выводе как есть.
- **S3:** шапка вида `[ssh <хост>] <команда>` — коротко и честно.

Дополнительно в ssh-режиме:
- показывать в `status`: «сессия: ssh на <хост>»;
- не гонять маркер-ART в потенциальные TUI/интерактив (предупреждать);
- возможность ручной метки хоста.

## Уникальный токен маркера

Сейчас маркер фиксированный: `___END_OF_COMMAND___:<exit>:<pwd>`.
- Риск: если вывод команды содержит эту строку — захват оборвётся рано.
- Предложение: уникальный токен на команду (`___END_OF_COMMAND_<random>___`), слушатель ищет
  именно текущий токен. Убирает коллизии, чуть безопаснее.

## Маркеры в ssh — известные ограничения (напоминание)

- Команды, читающие stdin (`sudo` пароль, `read`, `cat` без аргументов, `less`, REPL `mysql`),
  и TUI (`vim`/`nano`/`top`) — маркер уйдёт во ввод приложения или вообще не напечатается.
- Защита: `is_command_interactive` (не пускает часть команд в захват) + `_capture_timeout` (60 c).
