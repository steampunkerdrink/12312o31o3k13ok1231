# Changelog

История заметных изменений проекта.

Версия хранится в `config_manager.VERSION` и дублируется в `version.txt`.
Формат разделов: `## [версия] — дата`, подразделы Добавлено / Изменено / Исправлено.

---

## [5.7.0] — 2026-10-11

### Добавлено
- Тоггл пользовательских кнопок `keyboard_custom.txt` (`true`/`false`) — скрывает только
  пользовательские кнопки из `keyboard_list.txt`, системный ряд остаётся.
- Авто-закрытие простаивающих сессий: файл `idle_timeout.txt` (секунды, `0` = выключено).
  Таймер сбрасывается и по вводу команд, и по выводу PTY.

### Изменено
- Определение пользователя/промпта больше не хардкодит `root@` и `#`: берётся реальный
  пользователь (`getpass`) и обобщённая регулярка промпта (поддержка non-root `$`).
- Аккуратное завершение: при остановке бота (shutdown/SIGTERM) дочерние PTY убиваются.

## [5.6.0] — 2026-10-11

### Добавлено
- Статус «печатает…» при выполнении команд (`messages.setActivity`; сообщений не создаёт).
- Уведомление при входе в интерактивный режим.
- Приветствие админам «🟢 Бот запущен [vX]» при старте бота.

### Изменено
- Маркер окончания команды теперь несёт код возврата: `___END_OF_COMMAND___:<exit_code>:<pwd>`.
  При ненулевом коде в заголовке пути показывается `⚠️ exit N`.

## [5.5.1] — 2026-10-11

### Изменено
- В `status` метрика CPU теперь показывает реальную загрузку в **процентах** (сэмпл `/proc/stat`),
  а не число ядер. Число ядер перенесено в строку с `load`.

## [5.5.0] — 2026-10-11

### Добавлено
- Команда `status` / `статус` (и кнопка `📊 Статус`): статус бота (версия, uptime,
  режим, клавиатура, задержка, флуд), сессии (PID, папка, режим, последняя команда)
  и сервера (hostname, пользователь, CPU, uptime, load, RAM, диск).
  Каждая метрика — best-effort; при недоступности выводится `н/д` (работает и не из-под root).

## [5.4.5] — 2026-10-11

### Исправлено
- Запоздалый вывод после `reset` / `hard-reset` («мусорный хвост» с заголовком пути
  старой команды). Добавлены токены сессий `shell_worker.session_tokens[user_id]`:
  при сбросе токен снимается, и старый слушатель больше ничего не отправляет.

## [5.4.4] — 2026-10-11

### Исправлено
- В ART-режиме интерактивные команды (`ssh`, `apt`, `nano`, `mysql`, `ufw`)
  убивались 120-секундным лимитом art-подпроцесса. Теперь они распознаются как
  интерактивные и идут в живую PTY-сессию; картинкой рендерятся только обычные команды.

## [5.4.3] — 2026-10-11

### Добавлено
- Отступы (padding, 24 px) вокруг содержимого картинок. Цвет фона полей берётся
  из углового пикселя изображения.

## [5.4.2] — 2026-10-11

### Исправлено
- Геометрия «терминального арта»: полублочные символы (`▀▄█`, например
  `qrencode -t ansiutf8`) теперь рендерятся как 1 модуль в ширину × 2 модуля в высоту.
  Раньше ячейка делилась ещё и по горизонтали → QR растягивался и был нечитаем.

## [5.4.1] — 2026-10-11

### Добавлено
- Дублирование логов и трейсбеков `vkbottle` (модуль `logging`) в `bot_server.log`,
  чтобы не лезть в `journalctl`.

## [5.4.0] — 2026-10-11

### Добавлено
- Команда `art: <команда>` — выполняет команду в текущей папке сессии и присылает
  результат картинкой (PNG).
- Модуль `terminal_render.py`: парсер ANSI/SGR и рендер в PNG (текст и полублочная графика).
- Режимы вывода кнопками `🖼 ART` / `📄 Текст` (флаг `config_manager.art_mode`).
- В лог пишется включение/выключение ART-режима.

### Изменено
- Добавлена зависимость `Pillow`; `vkbottle` поднят до `>=4.7.0`.

### Исправлено
- Загрузка картинок в VK: перекодирование в JPEG (photo-сервер VK надёжнее принимает
  JPEG), несколько попыток загрузки, фолбэк-отправка документом, показ ошибки загрузки
  прямо в чате, гарантированный ответ при любом сбое (бот не молчит).

## [5.3.0] — 2026-10-10

### Исправлено
- Кнопка `Hard Reset` срабатывала как обычный сброс: подстрока `reset` в `💀 hard reset`
  ловилась проверкой обычного сброса. Список команд хард-ресета вынесен в `HARD_RESET_COMMANDS`.

### Изменено
- Единый источник версии `VERSION` в `config_manager.py`; общий логгер `log_message` там же.
- `os.dup()` для writer-дескриптора PTY (устранено двойное использование одного fd).
- Вместо захардкоженного хоста — `socket.gethostname()`.
- Беззвучные `except: pass` в `config_manager` заменены на логирование.

### Добавлено
- Файл `AGENTS.md` (памятка для ИИ-ассистента).
